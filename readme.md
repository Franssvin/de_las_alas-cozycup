# Cozy Cup Cafe

## Project Description
Cozy Cup Cafe is a simple and welcoming website created to represent a fictional coffee shop. The purpose of the site is to give users an idea of what the cafe offers by showing its menu, background story, location, and contact details. The website uses a modern but easy-to-use design so visitors can navigate it comfortably and enjoy the overall experience.

## Features
- Responsive and clean cafe-themed design  
- Menu display with images and descriptions  
- Easy-to-navigate layout  
- Customer-friendly interface  
- Simple and lightweight structure
